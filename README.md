# Шпаргалка по работе с Git

Небольшое практичное напоминание о том, как работать с Git и GitHub.

---

## Основные понятия

**Репозиторий (repository)** — папка проекта, в которой Git хранит историю изменений.  
**Коммит (commit)** — зафиксированное изменение в коде.  
**Ветка (branch)** — независимая линия разработки.  
**Merge** — объединение изменений из одной ветки в другую.  
**Remote** — удалённый репозиторий (например, GitHub).  
**HEAD** — текущая точка, на которой вы стоите (последний коммит).

---

## Инициализация проекта

Создаёт новый репозиторий в текущей папке.
```bash
git init
```
Клонирует существующий удалённый репозиторий.
```bash
git clone https://github.com/user/repo.git
```

## Работа с файлами
Показать состояние репозитория: изменённые, добавленные или неотслеживаемые файлы.
```bash
git status
```

Добавить файлы в индекс (к следующему коммиту).
```bash
git add filename
git add .
```
Создать коммит.
```bash
git commit -m "Сообщение коммита"
```
Просмотреть историю.
```bash
git log
```

## Работа с удалённым репозиторием
Посмотреть привязанные удалённые репозитории.
```bash
git remote -v
```
Добавить удалённый репозиторий.
```bash
git remote add origin https://github.com/user/repo.git
```
Первая отправка ветки.
```bash
git push -u origin main
```
Отправка последующих коммитов.
```bash
git push
```
